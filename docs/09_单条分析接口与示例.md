# 单条分析接口与解释卡示例

> 对应代码：`src/lib_infer.py`、`src/10_inference_service.py`、`src/11_export_explanation_cards.py`  
> 对应产物：`output/inference_self_test.json`、`output/explanation_cards.json`、`dashboard/single.html`  
> 能力边界：只支持**文本 + 图像**；不伪造视频/语音；强度是概率映射演示值，不是人工 −3~3 强度标注。

## 1 这个模块解决什么问题

大屏回答“整体舆情怎么样”，单条分析回答“这一条为什么这样判”。单条分析输出：

1. **极性**：负面 / 中性 / 正面；
2. **三类概率**：模型对三个类别的 softmax 概率；
3. **门控权重**：文本、图像各自的融合权重，以及主要参考模态；
4. **强度演示值**：由 `3 × (P(正面) − P(负面))` 映射到 −3~3 的整数，仅用于界面展示；
5. **文本证据**：删除关键词/字符片段后，真实类概率下降最多的 top-k；
6. **图像证据**：仅图像场景下，3×3 区域逐块灰色遮挡后的概率下降；
7. **边界声明**：弱标签、非因果、不用于个体判断。

## 2 启动方式

### 2.1 先确认模型存在

```bash
python src/04_modeling.py
```

需要以下文件：

- `output/models/baselines.joblib`
- `output/models/gated_fusion.pt`
- `data/processed/image_features.npy`
- `data/processed/image_stats.csv`

### 2.2 跑一次自检

```bash
python src/10_inference_service.py --self-test
```

输出：`output/inference_self_test.json`。自检会跑两条示例：

- `text_only`：只输入文本；
- `text_image`：输入文本 + `data/crawl/` 中的一张配图。

### 2.3 启动 HTTP 服务

```bash
python src/10_inference_service.py --serve --host 127.0.0.1 --port 8000
```

- 如果安装了 `fastapi` + `uvicorn`，自动使用 FastAPI，自带 `GET /docs`；
- 如果未安装，自动回退到 Python 标准库 `ThreadingHTTPServer`，接口路径一致；
- 默认只监听 `127.0.0.1`，不对外网开放。

当前环境未安装 FastAPI，因此实际运行的是标准库回退；这不影响接口契约。安装命令：

```bash
python -m pip install fastapi uvicorn
```

## 3 接口契约

### 3.1 `GET /health`

响应示例：

```json
{
  "status": "ok",
  "loaded_at": "2026-10-27 16:38:39",
  "modalities": ["text", "image"],
  "model_dir": "G:\\大数据赛道\\微博多模态舆情\\output\\models"
}
```

### 3.2 `POST /predict`

请求字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | string | 是 | 原始微博文本；服务内部会做清洗 |
| `image_path` | string | 否 | 项目根目录相对路径，如 `data/crawl/images/wb_xxx.jpg` |
| `image_base64` | string | 否 | `data:image/jpeg;base64,...` 或纯 base64；与 `image_path` 二选一 |
| `explain` | bool | 否 | 默认 `true`；`false` 时跳过 token/区域遮挡，速度更快 |

请求示例（PowerShell）：

```powershell
$body = @{
  text = "武汉加油，感谢一线医护人员！"
  image_path = "data/crawl/images/wb_b9082d1889d767e4.jpg"
  explain = $true
} | ConvertTo-Json

Invoke-RestMethod -Uri http://127.0.0.1:8000/predict `
  -Method Post -ContentType "application/json; charset=utf-8" `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

curl 示例：

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text":"武汉加油，感谢一线医护人员！","explain":true}'
```

## 5 离线解释卡页面

```bash
python src/11_export_explanation_cards.py
```

输出：

- `output/explanation_cards.json`：3 条示例的完整 JSON；
- `dashboard/single.html`：离线单条页，双击即可打开，不需要服务器。

页面包含：

1. 左侧配图与真实标签；
2. 右侧预测、概率条、门控条、强度演示；
3. 文本证据 chips：token + 概率下降；
4. 图像 3×3 网格：红色表示删除后概率下降（支持原预测），蓝色表示上升；
5. 底部边界声明。

示例选择策略：每个真实类别优先选“预测正确且置信度高”的样本，仅用于展示解释链路；**示例不代表总体准确率**，总体指标见 `output/models_metrics.json`。

当前 3 条示例：

| post_id | 真实标签 | 预测 | 门控（文本/图像） | 单条耗时 |
|---|---|---|---|---:|
| `wb_b9082d1889d767e4` | 负面 | 负面 | 99.3% / 0.7% | 约 0.8 s |
| `wb_6d42bd0740acb4ef` | 中性 | 中性 | 99.6% / 0.4% | 约 0.4 s |
| `wb_cab09c1129bbbbdc` | 正面 | 正面 | 99.96% / 0.04% | 约 0.4 s |

> 单条耗时随机器负载变化，以 `output/explanation_cards.json` 的 `latency_ms` 为准。

## 6 解释方法与边界

### 6.1 文本证据

- 先用 jieba + 词性过滤抽关键词；
- 短文本关键词不足 3 个时，回退为字符片段（2 字窗口/3 字窗口）；
- 逐个删除候选片段，重算 TF-IDF/SVD 特征与模型概率；
- 记录“原预测类概率下降”，降序取 top-k。

这不是积分梯度，也不是因果效应；它回答的是“删掉这个词，模型当前判断会松动多少”。

### 6.2 图像证据

- 在**仅图像场景**下，把图片切成 3×3；
- 逐区域填充灰色，重算 ResNet18 + 统计特征；
- 记录原预测类概率下降，降序取 top-k。

完整模态下门控主要依赖文本，图像遮挡的概率变化接近 0，这是预期结果，不应包装成“模型看懂了图像”。

### 6.3 强度演示值

```python
intensity = clip(round(3 * (P(正面) - P(负面))), -3, 3)
```

它没有经过强度回归训练，也没有人工 −3~3 标签校准。报告中必须写“强度演示值”，不能写“强度预测 MAE/Pearson”。

## 7 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| `缺少 output/models/...` | 没跑 04 | 先运行 `python src/04_modeling.py` |
| `ResNet18 不可用` | torchvision 权重缓存缺失/无网络 | 预下载权重，或改用已有 `image_features.npy` 做批量实验 |
| 端口被占用 | 8000 已被占用 | `--port 8010` |
| 返回 400 `文本为空或过短` | 清洗后 <2 字 | 换一条有实际内容的文本 |
| 图片不显示 | `image_path` 不是项目根目录相对路径 | 用 `data/crawl/images/...` 或绝对路径 |
| 解释很慢 | 图像 3×3 需要 9 次 ResNet 前向 | `explain=false` 或 `explain_image` 关闭图像解释 |
| FastAPI 没生效 | 未安装 fastapi/uvicorn | 安装后重启；标准库回退接口一致 |
