## 1 数据来源

### 1.1 主数据源

| 项目 | 内容 |
|---|---|
| 数据集 | Weibo and Twitter datasets（微博图文情感子集） |
| 发布平台 | Science Data Bank（ScienceDB） |
| DOI | `10.57760/sciencedb.j00133.00366` |
| 许可 | CC BY 4.0 |
| 时间范围 | 2020-01-01 ~ 2020-02-19 |
| 原始图文记录 | 64,347 条 |
| 标签 | -1 负面 / 0 中性 / 1 正面 |
| 内容 | 微博正文、图片、情感标签；配套 100k 文本表含发布时间与账号 |

数据集页面：`https://doi.org/10.57760/sciencedb.j00133.00366`。

### 1.2 使用到的文件

| 文件（zip 内） | 内容 | 本项目用途 |
|---|---|---|
| `dataset/Weibo/train_dataset/image_text_label.csv` | 微博 ID、正文、图片 URL、情感标签 | 图文主表、标签、图片抽取 |
| `dataset/Weibo/train_dataset/image/{id}.jpg` | 与主表对应的图片 | 图像特征与建模 |
| `nCoV_100k_train_labled.csv` | 微博 ID、发布时间、账号、正文、图片 URL、标签 | 时间回填、1,000 条落盘样本 |
| `nCov_10k_test.csv` | 文本测试集（GBK，含少量坏字节） | 备用，不进入主实验 |

### 1.3 为什么不是实时爬微博

项目红线要求：只采公开页面、遵守 robots.txt、≥2 秒/请求、不登录、不绕验证码/反爬、不碰个人信息。微博站内接口/用户页在未登录状态下返回 403，若强行突破会违反红线。因此：

- 主实验使用 ScienceDB 公开许可数据集，可复现、可审计；
- 图片从官方 zip 精确抽取，不逐张请求 CDN；
- 另提供 `01b_collect_public.py` 通用合规采集器（robots 检查、限速、失败重试、仅公开页面），用本地 fixture 做 6 项自检，证明采集链路具备合规能力；
- 1,000 条落盘样本明确标注为“公开数据集导入”，不冒充实时爬取。

## 2 数据规模与口径

### 2.1 从原始到有效

| 阶段 | 数量 | 说明 |
|---|---:|---|
| 原始图文记录 | 64,347 | 主表全部行 |
| 合法标签 + 有效文本 | 63,091 | 去除非法标签 52 条、空/过短文本 |
| 正文去重后 | 56,644 | 删除重复 6,447 条 |
| 有日期 | 20,423 | 覆盖率 36.05%，精确文本匹配回填 |
| 建模样本 | 12,000 | 每类 4,000，分层抽样 |
| 训练/验证/测试 | 8,400 / 1,800 / 1,800 | 70%/15%/15%，种子 42 |
| 外部无图测试 | 3,000 | 每类 1,000，图像真实缺失 |
| 落盘样本 | 1,000 | 匿名 user_id + 时间 + 文本 + 图片 |

### 2.2 全量标签分布

| 类别 | 帖子数 | 占比 |
|---|---:|---:|
| 负面（-1） | 7,942 | 14.02% |
| 中性（0） | 32,324 | 57.07% |
| 正面（1） | 16,378 | 28.91% |
| 合计 | 56,644 | 100% |

全量中性占近六成，类别不平衡明显。建模样本按类别分层抽取，每类 4,000 条，避免模型“全猜中性”；但**分层抽样改变了类别先验**，因此模型指标不能直接解读为全量线上的准确率。

### 2.3 日期回填口径

- 来源：`nCoV_100k_train_labled.csv` 的发布时间；
- 方法：对正文做 NFKC、去 URL/@/空白、统一标点后，与 100k 表正文做**精确匹配**；
- 结果：20,423 / 56,644 = 36.05%，覆盖 2020-01-01 ~ 2020-02-19 共 50 天；
- 未匹配到的帖子**不推测日期**，趋势分析只使用有日期子集；
- 建模样本日期覆盖率 40.5%，仅用于描述性统计，不作为模型特征（避免时间泄漏）。

**重要局限**：36.05% 的覆盖率意味着趋势结论只代表有日期子集，不能代表全量时间分布。报告中所有趋势数字均标注“有日期样本”。

### 2.4 建模样本与外部测试

- 建模样本：12,000 条，三类各 4,000；固定种子 42，分层 70/15/15；
- 外部无图测试：3,000 条，来自同一公开数据的文本子集，每类 1,000；**图像真实缺失**，不是人工置零；
- 外部集与测试集不重叠；外部集文本更短、事件阶段不同，存在分布漂移。

### 2.5 标注模板与人工标注状态

`data/annotation/annotation_template.csv` 是 30 条候选样本的**空白标注模板**，字段包括：

| 字段 | 说明 |
|---|---|
| `item_id` | 候选样本的 `post_id` |
| `event` | 事件名（待填写） |
| `post_type` | 纯文本/图文/视频（模板暂标图文） |
| `text` | 正文 |
| `annotator_a` / `annotator_b` | 双人极性标注（-1/0/1 或 负面/中性/正面） |
| `intensity_a` / `intensity_b` | 双人强度标注（-3~3） |
| `adjudicated_label` / `adjudicated_intensity` | 第三人裁决结果 |
| `notes` | 备注 |

**当前状态**：模板已生成，但标签字段全部为空；项目**没有完成**方案要求的 1,500 条双人标注、100 条预试与 Kappa 记录。`output/annotation_self_test.json` 中的 Kappa 来自合成数据，只证明计算链路可运行，不能作为人工标注一致性结果。

### 2.6 缺失与删除实验的数据口径

`output/missing_experiments.json` 不是新数据，而是对固定 test split（1,800 条）做的三组扰动实验：

1. **缺失比例**：随机屏蔽 10%/30%/50%/70% 样本的整条模态；
2. **缺失位置**：把文本 256 维或图像 519 维特征的一段连续区间置零（静态特征代理，不是视频时间轴）；
3. **删除实验**：删除 top-k token/图像区域 vs 随机删除 k 个。

所有实验不参与训练/调参，随机种子与测试集划分固定；底表在 `output/tables/缺失比例曲线.csv`、`缺失位置曲线.csv`、`删除实验.csv`。

## 4 清洗与预处理规则

### 4.1 文本清洗

1. Unicode NFKC 归一化；
2. 去除 URL、`@用户名`、微博尾巴（“展开全文”“网页链接”等）；
3. 去除私用区字符、控制字符、连续空白；
4. 保留 `#话题#`，统一全半角；
5. 常见表情映射为情感词：`[泪]`→“难过”、`[加油]`→“鼓励”、`[赞]`→“支持”等；
6. 清洗后长度 ≥4，且至少含一个中文或字母，才视为有效。

### 4.2 去重

- 按清洗后正文做完全重复去重，保留首次出现；
- 不去除“相似但不完全相同”的转发文本，避免误删不同立场；
- 去重删除 6,447 条，56,644 条进入分析。

### 4.3 图像处理

- EXIF 转正、统一 RGB；
- ResNet18 输入 224×224，ImageNet 均值/方差归一化；
- 冻结特征 512 维，L2 归一化；
- 7 维统计标准化后 ×0.5；
- 损坏图片返回零向量并记录，不中断流水线（本次 0 张损坏）。

### 4.4 省份与话题标签

- 省份：省级行政区全称/简称 + 主要城市别名；统计“文本提及”，不是用户定位；
- 话题标签：正则 `#([^#]{1,30})#`，去除纯数字/纯符号；
- 两者都只用于聚合分析，不进入模型特征（避免把“提及湖北”误学成“负面”）。

## 5 匿名化与隐私

### 5.1 处理规则

| 原始信息 | 处理 | 下游是否可见 |
|---|---|---|
| 微博 ID | `sha256(id)[:16]` → `post_hash` | 仅哈希 |
| 账号名 | `u_` + `sha256(account)[:16]` → `user_id` | 仅伪匿名 ID |
| 昵称 | 不读取、不输出 | 否 |
| 图片 URL | 仅内部溯源 | 否 |
| 发布时间 | 落盘样本到分钟；建模到天 | 是（粗化） |
| 图片 | 以 `post_hash.jpg` 命名 | 是（无 EXIF 个人信息） |

### 5.2 文件隔离

| 文件 | 内容 | 是否提交 |
|---|---|---|
| `data/crawl/weibo_1000.csv` | 匿名样本表 | 是 |
| `data/crawl/images/` | 1,000 张图片 | 是（按平台大小限制） |
| `data/crawl/manifest.json` | 统计与来源 | 是 |
| `data/crawl/README.md` | 字段与合规说明 | 是 |
| `data/crawl/_internal_provenance.csv` | 原始微博 ID、图片 URL | **否** |
| `data/crawl/_internal_account_map.csv` | 原始账号名映射 | **否** |
| `data/raw/dataset.zip` | 2.2 GB 原始数据 | **否** |
| `data/raw/provenance.csv` | 原始 ID/URL 溯源 | **否** |

### 5.3 使用边界

- 只做聚合舆情分析，不做个体用户画像、不推断身份、不自动处置；
- 省份是文本提及，不是用户位置；
- 情感标签为公开数据集弱标注，不能作为个体心理状态判断；
- 引用数据时保留 DOI 与 CC BY 4.0 署名。

## 7 数据局限

1. **日期覆盖仅 36.05%**：趋势结论只代表有日期子集；未匹配帖子不推测日期。
2. **弱标注噪声**：标签来自公开数据集弱标注，中性/负面边界模糊；混淆矩阵中互错较多。
3. **图像信号弱**：配图以信息性图片为主（截图、地图、口罩、新闻画面），图像单模态 Macro-F1 仅 0.4431。
4. **领域漂移**：2020 年疫情早期微博，不能直接外推到其他事件/平台。
5. **分层抽样改变先验**：建模样本三类均衡，线上全量中性近六成，部署需重新校准。
6. **落盘样本非实时**：1,000 条为公开数据集导入，不是实时爬取；实时接入需另行合规评估。
7. **省份为文本提及**：不能据此推断用户地域或地域情绪。
8. **没有视频/语音数据**：当前只有文本 + 图像，无法验证 CH-SIMS/MOSEI 的三模态能力。
9. **没有人工强度标签**：模型侧强度是概率映射演示值；标注模板中的强度字段为空，不能计算强度 MAE/Pearson。
10. **没有事件字段**：当前为固定随机划分，无法做事件级隔离测试；同事件相似帖子可能跨集。
